# Platform Roadmap

**Date**: 2026-09-12
**Status**: Delivery sequence with Feature 002 locally implemented; hosted/live acceptance remains
open. Later platform capabilities are future work.

VerityCX will demonstrate grounded banking support, durable multi-agent execution and controlled
human escalation. The benchmark supplies the business environment; the platform owns orchestration,
policy enforcement, persistence, service integration and operational evidence.

## Delivery Sequence

| Increment | Scope | Evidence required before completion |
| --- | --- | --- |
| 001: acquisition foundation | Finish existing acceptance work without expanding its scope. | Three-OS hosted evidence, measured acquisition, official smoke, data-policy and documentation review. |
| 002: durable knowledge support | Intent routing, knowledge specialist, policy enforcement, typed state, provider contract, PostgreSQL checkpoints, minimal FastAPI, restart/retry behavior, pending escalation and sanitized tracing. | Grounded answer, multi-turn restart recovery, source isolation, adversarial cases and truthful escalation; see Feature 002 criteria. |
| Next: Chatwoot handoff | AgentBot webhook adapter, event deduplication, durable delivery tracking, human ownership, contextual summary and controlled return to bot. | Real inbox handoff, no bot replies during human ownership, retry/reorder/restart tests and successful authorized return. |
| Next: account operations | Synthetic-state adapter and account specialist; per-tool authentication, policy and approval enforcement. | Allowed operations succeed; denied operations leave state unchanged; retries do not repeat actions. |
| Next: transactions/disputes | Specialist for supported transaction/dispute tools and cases; high-risk escalation. | Supported scenarios complete with tool evidence and policy compliance; unsupported cases escalate. |
| Next: deployment and evaluation | Docker packaging, reproducible local stack, full LangSmith evaluation integration, isolated benchmark runner and final security suite. | Reproducible deployment, pinned evaluation configuration, baseline comparison, failure analysis and portfolio walkthrough. |

Only Feature 002 receives a feature directory now. Later feature numbers and exact scope are assigned
when their specifications are created. Tracing, adversarial tests and the threat model evolve with
each increment; they are not deferred until final packaging.

## Design Choices

Build a complete knowledge conversation before adding operational tools. This exposes authentication,
state, replay and evidence problems while business side effects are absent. An infrastructure-first
approach delays useful demos; implementing all specialists at once couples business and orchestration
failures. The incremental workflow approach is selected for this portfolio.

Start with one provider adapter and a deterministic substitute. Add a second internal or vendor agent
only when contract compatibility can be demonstrated. Use a simple section-based lexical retrieval
baseline initially; introduce embeddings only through a measured retrieval improvement feature.

## Evaluation Strategy

Feature 002 uses project-authored questions and synthetic documents, frozen before acceptance runs.
They test product behavior and do not produce an official benchmark score. The eventual benchmark
runner must be an isolated evaluation consumer; agents cannot access expected answers, reference
actions or grading artifacts. Review and explicitly allow-list any additional upstream execution
code before integration, under the existing [data policy](data/tau3-banking.md).

For final evaluation, compare a single-agent baseline and the multi-agent platform using the same
model, tool surface, allowed corpus, budgets and frozen task set. Record task success, routing,
retrieval/grounding, policy violations, duplicate effects, handoff, latency and cost. Separate local
fixtures, official benchmark results and human review; report failures and sample sizes. Freeze
configuration before held-out evaluation and do not tune against held-out answers.
